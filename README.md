# College Event Management

A collaborative project to plan, organize, and document a college event.

## Project goals
- Record event details and objectives.
- Plan activities and event schedules.
- Estimate and track the budget.
- Assign responsibilities to student teams.
- Collect feedback after the event.

- `activities.md` – activities and competitions
- `budget.md` – estimated and actual expenses
- `team-responsibilities.md` – team roles and tasks
- `schedule.md` – event-day timetable
- `feedback.md` – feedback form and summary

## Getting started
1. Update `event-details.md` with your college's event information.
2. Add planned activities to `activities.md`.
3. Update the budget and team assignments.
4. Finalize the schedule before event day.
5. Record feedback after the event.

## Collaboration
Use GitHub Issues to assign tasks and track pending work. Ask team members to update the relevant Markdown files.
